SangeetPitara - Play Close for Windows (x64)

1. Extract this whole ZIP to a folder.
2. Join the Android host's Wi-Fi/hotspot.
3. Run "Start Play Close.cmd" and keep its window open.
4. Paste the complete invite copied from the updated Android host app.
5. Join, ask the host for control, then select "Share screen / system audio".
6. In Chrome or Edge, choose Entire screen + Share system audio, or a browser
   tab + Share tab audio. The browser's confirmation is always required.

Only audio is sent. Screen video never leaves your laptop through this app.
The browser connects to a loopback-only local helper, which verifies the exact
host certificate from your invite before using the encrypted local connection.
No certificate installation, browser security changes or internet relay is used.
Download this package once; later local room use does not need internet.

Chrome/Edge and your OS determine which audio sources can be captured. Protected
content and some app/window audio may be unavailable. Saved-file sharing remains
available. Linux/macOS users can run the repository's desktop helper with Node
22+; this Windows download includes its own Node.js runtime and needs no install.

To stop the companion, leave the room and close its console window.
Use invites from trusted hosts and a password-protected hotspot.
Node.js and ws licenses are included in this package.
