# Local UI review — 8 November 2026

This is an uncommitted design iteration. Do not push, tag, deploy or replace public downloads until the owner approves the UI.

## Selected direction

- Mehfil / Dark: warm charcoal, restrained brass, editorial serif headings.
- Playground / Light: warm ivory, olive accents, softer surfaces.
- Exactly two choices, persisted independently on the web and Android. Previous dark palettes fall back to Mehfil.
- Minimal welcome screen with separate Create, Join and Play Close flows. Android download is website-only.
- Existing room, sharing approval, chat and diagnostic controls remain available. Health colors use theme tokens for readable light-mode status.
- Website, native Android views, approval dialogs and the bundled offline browser page use the two palettes. Theme changes keep the existing service-owned audio architecture.

## Room-layout correction after review

The owner requested references before the next full visual redesign. The desktop sidebar was making diagnostics tall and narrow. Room / People / Health tabs now sit above the content at every viewport size. People and Health use the full content width; the listening surface is hidden while those sections are selected, without unmounting capture or playback. Desktop health factors use two columns; phones use one. Existing health regression now checks full-width layout and advancing audio packet counts after switching sections.

Validation: web build and eight targeted desktop/phone regressions passed. No GitHub push, public deploy, or public APK replacement.
