## 1. Shortcomings Inventory (14)

### P0 — Must fix before prod (fidelity/bandwidth)
1. **Forced mono** — media-relay.mjs CHANNELS=1, capture worklet downmix mid+0.25*side. Stereo width lost, anti-phase instruments cancel.
2. **Raw PCM16** — 768 kbps mono / 1536 stereo, no Opus. 10 listeners = 7.6 Mbps egress, bursts drop despite 64KB cap.
3. **No FEC/PLC** — gap = silence. Existing Opus params in app.js only for WebRTC opt-out, never on relay.
4. **Level meter 0%** — app.js analyser wired to captureStream / wrong analyser. Screenshot proves it: LIVE NOW but 0% RMS.
5. **Resampler ceiling** — Hermite cubic (fix1) fixes dull treble vs linear but not polyphase/sinc. 44.1kHz alias residue vs native 48kHz.

### P1 — Latency/robustness
6. **Fixed 120ms target** — playout DEFAULT_TARGET_FILL 5760 fixed. Good avg but adds ~600ms glass-to-glass even on fiber; no adaptation to jitter.
7. **PI controller weak** — single gain 0.010, clamp 0.997-1.006, 15ms fade. Either wobbles or drifts; underrun decay 0.965 silence pops.
8. **Quant hard clip** — relay-pcm.js round*0x8000 hard clips at 0dBFS, harsh distortion on loud masters.
9. **Clarity filter** — DC high-pass gate 0.0001 alpha; unverified A/B, may thin music if engaged.
10. **No concealment** — underrun -> exponential decay to 0, not waveform repeat / PLC crossfade.

### P2 — Platform/deploy
11. **Single-process rooms Map** — server.mjs rooms=new Map(), 100/10 caps, Render restart wipes rooms, free sleep disconnects.
12. **TURN off** — log turnConfigured:false. STUN-only fails on Jio/Airtel CGNAT, fallback to PCM relay taxed.
13. **Background tab freeze** — Worklet throttled when tab hidden; Android browser cannot capture other app audio (needs APK foreground service).
14. **UX** — SYNC 40-400ms slider label "Sync" confusing, value mismatch history, no guidance for branch.
