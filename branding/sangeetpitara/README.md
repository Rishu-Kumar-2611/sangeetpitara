# SangeetPitara logo concepts

This folder contains ten square, vector-only logo directions for the rename from
RoomSound to SangeetPitara. The existing RoomSound theme is preserved through
deep wood, paper cream, brass, and listening green.

Open [`gallery.html`](gallery.html) to compare the concepts. Each adjacent SVG
can be scaled to launcher-icon, favicon, browser, and print sizes without raster
blur or zoom jitter.

## Concepts

1. Wave Lid Pitara — a music chest with a waveform lid.
2. Sitar Gourd Pulse — a simplified sitar resonator and signal.
3. Twin Tabla Mark — paired tabla drums with a shared ripple.
4. Tanpura Moon — a crescent resonator with sturdy strings.
5. Diya Eighth Note — a diya flame shaped as a musical note.
6. Peepal Leaf Wave — a leaf vein becoming a waveform.
7. Listening Room Arch — a private room containing shared sound.
8. Ghungroo Bell — a dance bell with a note-like clapper.
9. SP Monogram Seal — an app-first SangeetPitara monogram.
10. Raga Sunburst — a central sound source radiating outward.

## Selected identity

**05 · Diya Eighth Note** is the selected SangeetPitara logo. The web header and
favicon use its SVG directly; Android uses an adaptive vector derived from the
same paths for the launcher and in-app header. The other nine concepts remain
here as design history and are not active app branding.
